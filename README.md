# 🛋️ Mebel — Custom Furniture Workshop Landing & Interactive Demo

> Интерактивный лендинг и шоукейс для мебельного производства полного цикла с интерактивным квиз-калькулятором и каталогом работ.

---

## 🌟 О проекте

**Mebel** — это презентационный сайт-лендинг с высокой конверсией для производителей мебели на заказ:
- **Интерактивный первый экран (Hero):** Горизонтальный аккордеон категорий (Кухни, Шкафы, Гостиные, Мебель для бизнеса) с плавной анимацией.
- **Интерактивный Квиз (Калькулятор стоимости):** Пошаговый расчет за 3–4 шага (тип мебели $\rightarrow$ размеры $\rightarrow$ материалы $\rightarrow$ отправка заявки).
- **Каталог готовых проектов:** Фильтры по стилям (Лофт, Классика, Минимализм, Неоклассика), подробные карточки материалов и фотогалерея.
- **Коммерческие материалы:** Встроенная презентация, файлы коммерческого предложения (PDF/HTML) и материалы для встреч с заказчиками.
- **Готовность к продакшену:** Оптимизированные WebP изображения, поддержка мобильных устройств и быстрый отклик интерфейса.

---

## 🛠 Технологический стек

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+), Lucide Icons
- **Архитектура интеграции:** Telegram Bot API (моментальная доставка лидов и ответов квиза), PocketBase / SQLite для каталога
- **Оптимизация:** Сжатие медиа-ресурсов в WebP, PageSpeed 90+

---

## 🚀 Быстрый запуск демо

Для просмотра интерактивного демо перейдите в папку `demo/` и откройте файл `index.html` в любом браузере:

```bash
cd demo
# Либо запустите локальный веб-сервер:
npx serve .
```

Или дважды кликните по `ЗАПУСК_САЙТА.bat` в папке `demo/` (на Windows).
